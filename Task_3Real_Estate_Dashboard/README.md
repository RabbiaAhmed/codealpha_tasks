CodeAlpha Internship - Task 3: Real Estate Market Trends Dashboard
This project was completed as part of my CodeAlpha Power BI Internship.

Task:
Real Estate Market Trends Dashboard

Tools Used:
- Microsoft Power BI
- Excel

Dashboard Features:
- Total Properties
- Average Property Price
- Total Locations
- Average Bedrooms
- Property type analysis
- Property price by location
- Market demand and supply analysis
- Geographic hotspot and map insights
- Interactive charts and filters

 Project Objective:
To analyze real estate market data and create an interactive Power BI dashboard that provides insights into property prices, locations, property types, market trends, and geographic hotspots.
